## 一、现状与硬约束

- 抽屉 = 声明式注册表（`src/renderer/shared/tool-registry.js` 的 `TOOL_GROUPS`）+ 动作分发（`src/renderer/home/17-tool-drawer.js` 的 `DRAWER_ACTIONS`），现有 4 项：手记、统计、主题、设置。
- 新增一个工具的固定成本：注册表一行 + 分发一分支 + i18n 中英两键 + 可选图标 path + 可选 state 默认值；`validateToolRegistry` 与双语键测试自动把关新条目。
- 两端（桌面 + 菜单栏）共用同一注册表，**没有按端过滤字段**——若出现"仅桌面端"的工具需要先给注册表加 `modes` 字段，本计划书将其列为可选基建，不默认做。
- 技术红线：零运行时依赖；通知只走原生通道；不动打包签名身份（`package.json` / `builder-menu.json` 的 identity 与本机证书）；打包需 Node ≥ 20.19。

## 二、收录原则（什么功能配进抽屉）

1. **一步直达**：价值在"不翻页"，三击内完成核心动作；
2. **轻状态**：状态进共享 `state.json`（`ensureState` 合并自动兼容、两端实时同步），不造独立存储；
3. **即时反馈**：有动效/声音/实时图形，而不是又一个静态表单页；
4. **与核心循环咬合**：围绕时间块、打卡门禁、手记、积分做增量，不建平行系统。

按这四条筛掉了一批"看似合理实则平庸"的想法（见第五节落选记录）。

## 三、功能目录

### 第一批 · 日常动线（高频、轻、纯渲染端）

#### T1 每日一签（确定性激励语）

- **特点**：不是"随机弹一句"，而是"今天这一签"——同语言、同场景池、同一天，打开几次都是同一句，过零点才换，像抽黄历。翻牌动效 + 一键复制。
- **实现边界**：做——`pickQuoteOfDate(pools, sceneKey, dateKey, lang)` 纯函数（FNV-1a 哈希取索引）、场景池切换（复用现有 8 个池）、翻牌 CSS 动画；不做——句子收藏、自定义语料、历史签回看。
- **数据/文件**：不新增 state 字段，只读现有 `quotes`；新 `src/renderer/shared/quote-daily.js` + `src/renderer/home/18-daily-quote.js`。
- **测试**：领域测试——同参确定性、换日换签、空池/缺语言回退默认池；浏览器——翻牌、复制、语言切换即时生效。

#### T2 今日待办（块关联 + 手记联动）

- **特点**：待办可以"挂"到某个时间块上（"19:00 这块刷完一套阅读"），当前块名旁显示挂载数；晚间总结一键把未完成待办带进手记 `plan` 字段——待办从孤立清单变成作息系统的一环。
- **实现边界**：做——`todos: {date: [{id, text, done, blockKey?}]}`；增删勾、清已完成、挂块下拉（当日块）；手记面板加"带入未完成待办"按钮（仅预填，不自动保存手记）；不做——子任务、优先级、跨日重复、待办提醒。
- **数据/文件**：`src/renderer/shared/state-schema.js` `defaultState()` 加一行，`ensureState` 自动兼容；新 `src/renderer/shared/todo-model.js` + 面板模块。
- **测试**：`unfinishedTodosOf(date)`、`todosToPlanText()`（挂块按块名分组、无挂块归"其他"、空列表返回空串）；浏览器——增删勾、挂块、手记预填、两端同步。

#### T3 倒数日（D-day）

- **特点**：最近的倒数日可挂到**托盘标题**（`⏳87`），不打开任何面板也能天天看见；抽屉条目悬停即显天数。
- **实现边界**：做——`countdowns: [{id, name, date}]` 增删改、按剩余天数排序、过期灰显不自动删、托盘后缀开关（默认关）；不做——每年重复事件、农历、托盘多事件同显。
- **数据/文件**：新 state 字段；`tray:update` 的标题由渲染端拼好再发，主进程零改动。
- **测试**：`daysUntil`（当天=0、跨月跨年、过期为负）、托盘拼接函数（关/空/取最近）；浏览器——面板交互与 i18n；托盘实际显示属壳层，由用户安装后确认。

#### T4 冲刺模式（组合场景，非开关复读）

- **特点**：一键进入"冲刺"——通知静音 + 白噪自动开 + 条目显示剩余分钟，到期或当前块结束自动解除。它是一个**场景**，不是两个独立开关的另一种摆法。
- **实现边界**：做——`sprint: {until, noise: {tone, volume} | null}`；生效点为渲染端统一门卫 `canNotify(kind)`（收敛现有 `bridge.notify` / `sound:play` 全部调用点）；冲刺期仅保留块切换提示音，其余全静音；不做——按块自动冲刺规则、分级白名单静音（第一版二分：块提示 / 其他）。
- **测试**：`sprintState(now)`（未开/进行/到期）、`canNotify` 真值表（状态 × 通知类型）；浏览器——开关、倒计时显示、到期自动恢复、两端同步。
- **依赖**：T5 未做时白噪部分降级为仅静音，边界写死，互不阻塞。

#### T5 白噪音（块联动淡入淡出）

- **特点**：不是硬开关——专注块开始 2 秒淡入、进休息 3 秒淡出、回块再淡入，噪声像呼吸一样跟着作息走；棕噪的生成参数调校成近似雨声。
- **实现边界**：做——Web Audio 预生成 4 秒噪声 buffer 无缝循环（白/粉/棕，棕噪用一阶低通积分拟合雨声）、`fadeGain(t)` 纯函数、音色/音量/联动开关存 state；不做——音频文件、联网音源、多轨混合。
- **测试**：fade 曲线端点与中点数值、buffer 参数（长度/声道）；浏览器——点击播放（user gesture 合规）、切音色不爆音、联动开关行为。

### 第二批 · 复盘与数据（中频、深、纯渲染端）

#### T6 会话心电图

- **特点**：抽屉顶部一条实时"心电"SVG——过去 120 分钟每分钟一格：专注=尖峰、休息=低平、跳过=断格。今天节奏如何，一眼扫描，不用读数字。
- **实现边界**：做——`ekgSeries(dailyStats, nowSec)` 纯函数、SVG 渲染走 CSS 变量取色、悬停显示该分钟明细、bar 模式压缩为近 60 分钟；不做——历史回看、落盘、导出。
- **测试**：series 构造（空日/跨块/含 skip/正在休息/正在专注/nowSec 越界）；浏览器——实时走针、tooltip、双主题取色。

#### T7 与昨天同期

- **特点**：一行环境文案"比昨天同期 +23 分钟"；昨天这会儿还没打卡时，显示"昨天此时还没开始"而不是误导性的 −x。措辞规则是它的全部人格。
- **实现边界**：做——`deltaVsYesterdaySameTime(dailyStats, checkins, date, nowSec)` + 四种文案分支（领先/持平/落后/昨日未开始），放 T6 旁；不做——趋势图、目标对比（统计页已有）。
- **测试**：真值表全分支（昨日无数据/有数据未打卡/已打卡、跨零点、今天未打卡返回 null 不显示）。

#### T8 周报分享卡

- **特点**：把 `buildReport` 的数字渲染成一张能直接发出去的 PNG 竖卡（连击火焰、总时长、最佳日、迷你热力条）——导出从"备份"升级为"分享"，给学生一个真实的传播动机。
- **实现边界**：做——`cardData(weekMetrics)` 装配纯函数 + SVG 卡面模板（1080×1440、系统字体栈、复用 `svg-charts.js` 风格约定）→ canvas → PNG Blob 下载（复用设置页导出模式）；不做——多模板、上传、分享链接。
- **测试**：cardData 全 0 周回退与字段完整性；浏览器——出图、下载打开目检、深色模式配色。

#### T9 数据体检

- **特点**：对 `state.json` 做一致性巡检并给可执行结论：`gateStart` 之后"有专注分钟但无打卡"的孤儿日、未填理由的 skip、重叠的 extra、手记断档、过期倒数日——长期数据的"年度体检"。
- **实现边界**：做——`auditState(state) → [{code, severity, count, sample}]` 纯函数 + 报告面板；修复仅限白名单安全项（如一键清理空 extra），其余只报告不代劳；不做——改历史分钟数、跨天合并、任何不可逆操作。
- **测试**：本批测试密度之王——每条规则 2~3 个构造用例（触发/不触发/边界）；浏览器——报告渲染与修复按钮确认交互。

#### T10 学期进度

- **特点**：倒数日是"事件"，学期进度是"区间"——"本学期已过 43%，剩 78 天"，给没有单一 D-day 但有长跑感的人。
- **实现边界**：做——`semesters: [{id, name, start, end}]`（上限 3 个）、进度条 + 双端日期；不做——课表导入、假期自动扣除（可后批）。
- **测试**：`semesterProgress`（未开始/进行中/已结束/同日起止防零除）；浏览器——增删改与渲染。

### 第三批 · 壳层增强（需动主进程，逐项单独评审）

> 本批功能的核心逻辑仍抽成可测纯函数；但窗口、事件、快捷键本身浏览器测不到，**按 AGENTS 约定由用户安装后确认**，这是对"浏览器验证即可"的明示例外。

#### T11 舞台小窗（常驻悬浮环）

- **特点**：邮票大小置顶悬浮环（环形进度 + 当前块名 + 倒计时），拖到屏幕角落，在别的全屏应用外也能感知时间——比菜单栏再往外推一步。
- **实现边界**：做——新 `widget.html`（复用 shared 模型与 `svg-charts.js`，**不加载**抽屉/主页脚本）；`bootstrap.js` 照 `barWin` 模式建窗（alwaysOnTop / skipTaskbar）；位置存 state、启动时 clamp 到工作区；只读 `state:sync`，不发通知不写状态（提醒职责仍归 duty coordinator 的负责端）；点击唤起主面板；不做——点击穿透、多屏记忆、皮肤。
- **测试**：`clampWidgetBounds` 纯函数；渲染页内容浏览器可验；置顶/拖拽由用户实测。

#### T12 锁屏自动处置

- **特点**：合盖即"临时离开"——自动把当前块按跳过记为"锁屏"，解锁续上。专治"忘按跳过 → 假专注"这个数据污点，比任何图表都更能保护数据可信度。
- **实现边界**：做——powerMonitor lock/unlock 两条 IPC；决策抽纯函数 `lockDisposition(blocks, lockAt, unlockAt)`（锁屏 <2 分钟视为无感不记、只在专注块记、解锁已进下一块则只补 skip）；不做——暂停/改写时间轴、恢复后强弹窗。
- **测试**：`lockDisposition` 真值表（专注/休息/块边界、阈值两侧、跨块解锁）；事件流用户实测。

#### T13 全局快捷键

- **特点**：键盘型的"零像素抽屉"——⌥⌘S 跳过当前块、⌥⌘J 记手记、⌥⌘D 冲刺开关。
- **实现边界**：做——`globalShortcut` 主进程注册；**只有 duty coordinator 挂牌负责提醒的一端注册**（避免双端抢占，duty 变化时动态注册/注销）；动作经 IPC 下发渲染层复用同一批函数，不复制业务逻辑；注册冲突 fallback 提示；第一版键位固定，不做自定义 UI。
- **测试**：键位→动作映射表单测；实际触发用户实测。

## 四、实施节奏与依赖

- **第一批 T1–T5**：纯渲染端，可一次改完、一次打包验证；唯一依赖 T4↔T5 已写明降级边界。

## 五、落选记录（理由存档，防止回头重提）

| 想法 | 落选理由 |
|---|---|
| 自由番茄钟 | 与排程制核心冲突，会产生两套统计口径 |
| 句子收藏/自定义语料 | 等 T1 上线用使用频率说话 |
| 应用屏蔽/屏幕使用时间 | 需辅助功能权限且数据不可靠，收益配不上成本 |
| 云同步/账号体系 | 双端共享 state 已覆盖，云引入冲突合并，超出单机定位 |
| AI 手记总结 | 违背零依赖与隐私边界 |

## 六、统一工程约定（每个功能过一遍）

1. 领域逻辑一律落 `src/renderer/shared/` 纯函数 + `tests/` 用例，渲染层只做装配；
2. 注册表加行后 `validateToolRegistry` 与双语键测试自动把关，新图标必须进 `icons.js` 的 PATHS；
3. state 新字段只走 `defaultState()` + `ensureState` 合并，不写迁移脚本；
4. 通知相关一律在渲染端发送前加门卫，遵守"只走原生通道"，主进程不加过滤；
5. 签名配置、identity 证书一律不碰。
