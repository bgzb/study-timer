# study-timer 学习作息计时

一个为"间歇学习"设计的本地计时应用：按你的作息自动提醒什么时候专注学习、什么时候起身休息，带实时倒计时、今日时间轴、温和的随机激励语。

界面与全部业务逻辑都在 `index.html` 一个文件里，既可以作为独立 App 运行（推荐），也可以直接用浏览器打开。

## 安装版 App（推荐）

已打包为**两个独立的 App**（数据自动同步，可单独启动/退出，互不影响）：

- **`/Applications/study-timer.app`（桌面端）**：打开即显示主窗口；关闭（红钮 / Cmd+Q）即退出桌面端，不影响菜单栏端
- **`/Applications/study-timer-menu.app`（菜单栏端）**：无 Dock 图标，只驻留菜单栏——实时倒计时 + 点击弹出全功能面板；**负责全部提醒**（通知、铃声、统计、每日总结弹窗）。点面板底部「🖥 打开桌面端」可唤起桌面端
- 两 App 状态经共享文件秒级同步（作息/统计/手记通用）；只开桌面端时，桌面端会临时接管提醒
- 菜单栏右键：显示面板 / 打开桌面端 / 开机自启（自启的是菜单栏端）/ 退出
- 开机自启：桌面端或面板的 设置 → 数据 → 开机自启

### 重新打包

```bash
cd ~/Developer/study-timer
npm install          # 首次
npm run dist:all     # 产出 dist/mac-arm64/study-timer.app + dist/menu/mac-arm64/study-timer-menu.app
```

修改任何代码后重新打包即可更新 App。开发调试：`npm start` 跑桌面端，`npm run start:menu` 跑菜单栏端。

## 浏览器版（备选）

直接用 Chrome 打开 `index.html`。限制：窗口关闭后计时停止；建议在 Chrome 里
"更多工具 → 创建快捷方式 → 作为窗口打开"，把它装成独立窗口应用并保持打开。

## 快速上手

1. 首次打开会引导你开启**系统通知和提示音**（只需一次）
2. 点右上角 ⚙️ 打开设置，按需调整作息
3. 到点会收到系统通知：学习块开始 / 休息一下 / 时段完成 / 全天完成，每条都带时间段和一句随机的激励语

## 作息规则

默认作息（工作日与周末/节假日独立配置）：

| 时段 | 序列 | 结束时间 |
|------|------|----------|
| 上午 09:00 | 学40 · 休10 · 学40 | 10:30 |
| 下午 14:00 | 学40 · 休10 · 学40 · 休10 · 学40 | 16:20 |
| 晚上 20:00 | 学40 · 休10 · 学40 | 21:30 |

时段之间是大休（午饭午休、晚饭），不计时、不发提醒，到下一个时段开始时间自动恢复。

**序列写法**：数字从"学习"开始交替，如 `40 10 40` = 学40分 → 休10分 → 学40分。

**模式自动判定**（内置 2025–2026 国务院放假安排，可编辑）：
调休补班日 → 工作日作息；法定节假日 → 节假日作息；周六日 → 周末作息；其余 → 工作日作息。
点主界面的模式徽章可对今天手动覆盖（应对临时安排）。

## 主要功能

- **双语界面**：设置 → 数据 → 语言 可切换 中文/English，界面、通知、激励语全量切换；时段名（上午→Morning）在作息未改过时自动跟随
- **实时倒计时**：大字号显示当前块剩余时间，进度条与今日时间轴同步
- **随机激励语**：上午/下午/晚上首块有专属问候，学习块与休息块分池随机、不连续重复；可在设置里增删
- **跳过当前块**：提前结束当前学习/休息块，后续块自动前移
- **今日统计**：已完成学习块 n/N、累计专注分钟
- **提示音**：4 种内置音色（Web Audio 合成，无音频文件），音量可调
- **数据**：设置导出/导入 JSON，方便备份或换机

## 调试技巧

URL 带参数可把时钟拨到指定时刻预览各状态（自测用）：

```
index.html?t=09:20   # 学习中
index.html?t=09:45   # 休息中
index.html?t=12:00   # 大休等待
index.html?t=21:45   # 全天完成
```

## 通知不弹的排查

设置 → 提醒 → **通知诊断** 里有权限状态和直达按钮：

1. **系统设置 → 通知 → study-timer**：允许通知、样式选"横幅"、开启"播放通知声音"（设置里有按钮直达这一页）
2. **关闭专注模式/勿扰模式**——开启时横幅会被静默吞掉
3. **App 需处于运行状态**（安装版驻留菜单栏后台，一般无此问题）
4. 浏览器版：Chrome 地址栏锁图标 → 网站设置 → 通知设为允许

提示音在 App 内通过 macOS 系统音频（afplay）播放，音量可在设置里调大（最大约2倍增益）。
